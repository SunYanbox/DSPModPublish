# DSPEasy Exchange · EMC 交易面板

给戴森球计划加一个「万物皆可买卖」的 EMC 交易所（类似**等价交换**）：**卖**背包里的物品换 EMC，**买**已经解锁过的物品。所有物品按「资源基价 + 配方推导」自动定价，余额和已解锁清单随存档保存。

> 汇报问题时，写清「触发时在做什么」并尽量附上 `Player.log`（BepInEx 控制台里 `[EasyExchange]` 开头的行最有用）：[提交 Issue](https://github.com/SunYanbox/DSPModPublish/issues)
>
> 源码不在本仓库，这里是发布包与文档：[https://github.com/SunYanbox/DSPModPublish](https://github.com/SunYanbox/DSPModPublish)

## 怎么玩

- 按 `K` 打开面板（可在 BepInEx 配置里改键），面板贴屏幕左边缘、按住标题栏可拖动。
- **卖**：把物品拿在手上、在面板里左键一下 → 整组回收并解锁；「我的物品」列表里点一下卖 1 个、`Shift` 点卖光这一格；底部「卖出沙土」按钮把沙土按 100 沙土 = 1 EMC 回收。
- **买**：点「选择物品 ▾」挑目标（物品 / 建筑两页），填数量后点「购买」；列表里点行买 1 个、`Shift` 点买一组；购买行下方的「买×1 / 买×一组 / 买×MAX」是快捷买入。
- 只有**卖过或买过的物品**才会解锁购买。没解锁、没定价、背包放不下的物品不会成交（有弹窗提示）。

## 定价

- 单位是 **milli-EMC**（1000 = 1 EMC），面板显示三位小数，例如铁矿 0.10 EMC、结构矩阵 3.265 EMC。
- 27 项原始资源有基价，其余物品按配方推导：原料价总和 ÷ 产出总数（多产出按总数均摊），取所有可行配方里最便宜的一条；非产出型配方（对撞机、裂解等）也参与推导。
- 几条参考价：临界光子 55.2 EMC、反物质 27.6 EMC、反物质燃料棒 169.29 EMC、宇宙矩阵 49.83 EMC、蓄电器 4.14 EMC。
- 想改价：打开 `BepInEx/config/DSPEasyExchange/pricing.csv`，改「基价(milli)」列后重启游戏（清空 = 交给推导，填 `0` = 免费）；`[定价] 基价倍率` 可以整体缩放。

## 存档

- 余额与已解锁清单写在存档旁车 `<存档名>.mod.dat`（块 `EMC1`），不进原版 `.dsv`；新档从 0 EMC、0 解锁开始。
- **复制 / 备份存档时把 `.dsv` 和 `.mod.dat` 成对复制**，只拷 `.dsv` 会从 0 EMC 开始。删档时两份一起删。
- 自动存档的旁车跟随原版 `_autosave_0..3` 轮转（保留最近 4 次）：读哪一档，就恢复哪一档的余额与解锁。

## 原版统计

0.5.0 起，买卖会记入原版分析面板（`P`）的「累计」列：买入按整条制作链记「生产 + 中间产物生成并消耗」，卖出记「消耗」。我们只写累计列，分钟/小时曲线不会出现交易峰值。

## 安装

1. 装 **BepInEx 5.4.17（x64，Mono）**，进一次游戏确认 `BepInEx/plugins` 已生成（本包不含游戏本体与 BepInEx）。
2. 装 **DSPEasy Framework**（本模组的依赖，模组管理器会自动装上）。
3. 把 `DSPEasyExchange.dll` 放进 `BepInEx/plugins/`（用 mod 管理器则自动处理）。启动后控制台出现 `Loading [DSPEasy.Exchange 0.5.3]` 即加载成功。

要求的框架版本：`DSPEasy_Framework 0.2.32`。框架由所有 DSPEasy 模组共用，**只允许存在一份**，若之前手动装过旧版，请把那套旧文件删掉。

## 配置项（`BepInEx/config/DSPEasy.Exchange.cfg`）

> 升级提示：0.5.2 及更早的配置文件叫 `DSPMod.easyexchange.cfg`（旧插件 GUID 遗留），新版不再读取，热键与倍率会回到默认。想保留原来的设置，把 `BepInEx/config/DSPMod.easyexchange.cfg` 重命名为 `DSPEasy.Exchange.cfg` 即可（配置键名没变）。

| 配置 | 默认 | 说明 |
| ---- | ---- | ---- |
| `[界面] 面板热键` | `K` | 打开/关闭交易面板的按键 |
| `[界面] 交易日志` | 关 | 打开后每笔成交写一行 `[EMC]` 日志；排查问题时再开 |
| `[定价] 基价倍率` | `1.0` | 所有基价统一乘以该值（`0.5` = 半价，`2` = 双倍） |

## 兼容性

- 游戏本体：Dyson Sphere Program `0.10.35.29151`。
- 只读原版 `LDB`（物品 / 配方 / 科技），**不修改原版任何数值**。其它模组新增的物品：带配方的会按配方推导出价，没有配方的需要在 `pricing.csv` 里给它一个基价，否则视为未定价、不可交易。
- 与其它改价、改配方、改经济系统的模组同时安装时可能互相影响价格口径，遇到异常先只留本模组复现。
- 已知设计取舍：蓄电器与蓄电器（满）同价（4140）；沙土可以用地形改造无限获取，属于「慢速 EMC」而非漏洞（后续会加配置开关）。
