# DSPEasy Buildings · 改版建筑

给戴森球计划（Dyson Sphere Program）新增 **11 座独立于原版的超级建筑**：全部是新增物品（默认 ID `11500`–`11510`）与新增配方，不覆盖、不修改任何原版物品。物品 ID、科技 ID 与 **7 套游玩模式配方（默认 5）** 都可以在配置文件里改（见「配置项」）。

解锁方式：建造菜单里的新科技 **「改版建筑」**（前置科技：电磁学，研究完解锁全部 11 个配方）。

在哪找：11 座建筑的物品与配方都在本模组自己的位置里——物品选择器（物流塔、仓储、配送器、交易面板）与配方选择器（制造台、手搓合成器）多一页 **「改版建筑」**，建造栏多一个 **「改版」** 类别（在原有分类旁边）。原版的「物品 / 建筑」页与建造栏原有分类里不再混着它们。

> **本模组是超模建筑，不完全追求原版平衡性，慎用；提供几个游玩模式用于改变合成配方的平衡性。**

## 安装

1. 装 **BepInEx 5.4.17（x64，Mono）**。
2. 装 **DSPEasy Framework**（本模组的依赖，模组管理器会自动装上）。
3. 把 `DSPEasy.Buildings.dll` 放进 `BepInEx/plugins/`（用 mod 管理器则自动处理）。启动后控制台出现 `Loading [DSPEasy.Buildings X.Y.Z]` 即加载成功。

要求的框架版本：`DSPEasy_Framework 0.2.34`。框架只允许存在一份，若你之前手动装过旧版，请把那套旧文件删掉。

## 性能面板统计

原版分析面板（`P`）→「性能测试」→「CPU」列表的末尾会多出本模组的行：一级是模组合计，下面是各建筑的每帧平均耗时与占比，建筑下再细分它的主要逻辑（例如超级采矿机的全球采集、超级炮台的索敌与开火、太空超级防卫站的索敌窗口与溅射、超级研究站的吸取矩阵、超级黑箱超市的槽位维护与生产进度、超级电磁-火箭发射器的发射进度）。

统计只在面板打开、且勾选了「实时检测」时采样，关掉面板或取消勾选后没有额外开销。没在这一帧跑过的逻辑显示 `-`，属正常（例如防卫站 5 秒才检测一次、炮台空闲时会降频）。

## 配置项（`BepInEx/config/DSPEasy.Buildings.cfg`）

首次启动会按默认值生成这个文件：`[游玩模式] 方案 = 5`，`[科技] ID = 1999`，`[物品]` 下 11 个键（键名是建筑中文名）依次是 `11500`–`11510`。改完**重启游戏**生效。

### 游玩模式（`[游玩模式] 方案`）

`方案` 取 `0`–`6`，默认 `5`。切换只改 11 条配方的材料/产出和传送带、分拣器说明，不改建筑数值、物品 ID、科技解锁或存档；非法值会回退 `5`。

| 方案 | 定位 | 适合玩法 |
| --- | --- | --- |
| 0 | 保留早于 0.2.35 的旧配方 | 想沿用 0.2.34 的旧档、旧攻略或旧蓝图 |
| 1 | 开局 30 分钟 | 新开档，想快速度过前期 |
| 2 | 轨道级科学 | 已进入星际物流，用钢材/钛块/处理器/超级磁场环 |
| 3 | 稀有资源约束 | 用光栅石、刺笋结晶、单极磁石、可燃冰等稀有矿 |
| 4 | 终局造价 | 钛合金、框架材料、量子芯片、奇异物质 |
| 5 | 功能造价匹配（默认） | 按建筑功能强度定价，适合中后期正常推进 |
| 6 | 极简创意 | 只想造建筑，不想为材料跑产线 |

> 本版默认是方案 5，配方与 0.2.34 不同；想完全保持旧配方请把 `方案` 改成 `0`。

### 物品 ID / 科技 ID

- 什么时候要改：和其它新增物品 / 科技的模组撞号（典型症状是注入被跳过、建造栏里看不到本模组建筑，日志里有「已被『xxx』占用」或 `ArgumentException ... Key: 1999`）。本模组**不会自动避让**，撞号时只报错并放弃注入。
- **改了 ID 之后，旧存档里已建好的本模组建筑会变成 `Unknown Item`，科技也要重新研究**。请先把 ID 定下来再开档。
- 科技 ID 必须落在 `1000`–`1999`（`>=2000` 会被原版归到升级页，不出现在主科技树）；物品 ID 必须落在 `1`–`11999`。
- 配置文件读不出来时，注入会直接放弃并报错，不会悄悄退回默认 ID。

## 存档与蓝图

- 模组设置（采矿倍率、炮台/防卫站开关与射程、发射器开关、黑箱目标/配方/制造与物流开关、制造机槽等）写在存档旁边的 `<存档名>.mod.dat` 里，**不进 `.dsv`**。备份或迁移存档时请把 `.dsv` 与 `.mod.dat` 成对复制。
- 建筑设置会随原版蓝图一起保存（含在本模组附加数据里）。**跨环境（对方没装本模组）粘贴蓝图会丢建筑或报错**，这是已知限制。

## 兼容性

- 游戏版本：`0.10.35.29151`（Unity 2022.3.62f3c1，64 位）。
- 与 CommonAPI（MoreMegaStructure 等整合包的前置）共存：`0.2.33` 起修复了装上 CommonAPI 后本模组跳过注入、看不到建筑的问题；如仍异常，请附日志。
- 与其它新增建筑/物品的模组共存：默认占用 `11500`–`11510` 物品段与科技 `1999`，配方 ID 自动找空位；撞号时把配置文件里的 ID 改掉即可（见「配置项」），仍异常请把日志发我。
- 与其它会加物品页/建造分类的模组共存：本模组的「改版建筑」页签与「改版」类别会自动落在空闲位置，不会和别的模组抢同一页。
