# DSPEasy Buildings · 改版建筑

给戴森球计划（Dyson Sphere Program）新增 **11 座独立于原版的超级建筑**：全部是新增物品（默认 ID `11500`–`11510`）与新增配方，不覆盖、不修改任何原版物品。物品 ID 与科技 ID 都可以在配置文件里改（见「配置项」）。

解锁方式：建造菜单里的新科技 **「改版建筑」**（前置科技：电磁学，研究完解锁全部 11 个配方）。

> **没有调整平衡性，非常超模，慎用**
> 
> 汇报问题(Bug/Issue)：[github](https://github.com/SunYanbox/DSPModPublish/issues)
>
> 欢迎以评论方式提供意见：[征求 DSPEasy.Buildings 模组的平衡性调整意见 —— 合成配方方面](https://github.com/SunYanbox/DSPModPublish/issues/1)

## 安装

1. 装 **BepInEx 5.4.17（x64，Mono）**。
2. 装 **DSPEasy Framework**（本模组的依赖，模组管理器会自动装上）。
3. 把 `DSPEasyBuildings.dll` 放进 `BepInEx/plugins/`（用 mod 管理器则自动处理）。启动后控制台出现 `Loading [DSPEasy.Buildings 0.2.34]` 即加载成功。

要求的框架版本：`DSPEasy_Framework 0.2.32`。框架只允许存在一份，若你之前手动装过旧版，请把那套旧文件删掉。

## 配置项（`BepInEx/config/DSPEasy.Buildings.cfg`）

首次启动会按默认值生成这个文件：`[科技] ID = 1999`，`[物品]` 下 11 个键（键名是建筑中文名）依次是 `11500`–`11510`。改完**重启游戏**生效。

- 什么时候要改：和其它新增物品 / 科技的模组撞号（典型症状是注入被跳过、建造栏里看不到本模组建筑，日志里有「已被『xxx』占用」或 `ArgumentException ... Key: 1999`）。本模组**不会自动避让**，撞号时只报错并放弃注入。
- **改了 ID 之后，旧存档里已建好的本模组建筑会变成 `Unknown Item`，科技也要重新研究**。请先把 ID 定下来再开档。
- 科技 ID 必须落在 `1000`–`1999`（`>=2000` 会被原版归到升级页，不出现在主科技树）；物品 ID 必须落在 `1`–`11999`。
- 配置文件读不出来时，注入会直接放弃并报错，不会悄悄退回默认 ID。

## 存档与蓝图

- 模组设置（采矿倍率、炮台/防卫站开关与射程、发射器开关、黑箱目标/配方/制造与物流开关、制造机槽等）写在存档旁边的 `<存档名>.mod.dat` 里，**不进 `.dsv`**。备份或迁移存档时请把 `.dsv` 与 `.mod.dat` 成对复制。
- 建筑设置会随原版蓝图一起保存（含在本模组附加数据里）。**跨环境（对方没装本模组）粘贴蓝图会丢建筑或报错**，这是已知限制。

## 兼容性

- 游戏版本：`0.10.35.29151`（Unity 2022.3.62f3c1，64 位）。
- 与 CommonAPI（MoreMegaStructure 等整合包的前置）共存：`0.2.33` 起修复了装上 CommonAPI 后本模组跳过注入、看不到建筑的问题；如仍异常，请附日志。
- 与其它新增建筑/物品的模组共存：默认占用 `11500`–`11510` 物品段与科技 `1999`，配方 ID 自动找空位；撞号时把配置文件里的 ID 改掉即可（见「配置项」），仍异常请把日志发我。
